Project overview

Azri turns Git repositories into shareable explanation pages.

It runs locally as a CLI or as a self-hosted GitHub bot, processes any public repo or pull request through a six-stage LLM pipeline, and produces a single self-contained HTML file that explains both the what and the why.

Who it's for

  • Reviewer · Wants the why behind a PR before scrolling through 800 lines of diff.
  • New hire · Wants a one-page architecture tour without reading every README.
  • Tech lead · Wants a defensible record of decisions made during a release.
